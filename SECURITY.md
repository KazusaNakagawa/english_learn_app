# Security Policy

## Supported versions

Only the latest state of the `develop` branch receives security fixes. This
applies to the iOS app, the web app, and the AWS CDK backend in this repository.

| Version | Supported |
|---|---|
| Latest `develop` | Yes |
| Older commits | No |

## Reporting a vulnerability

Please do **not** report security issues in public issues, pull requests, or
discussions.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/KazusaNakagawa/english_learn_app/security/advisories/new)
(Security tab → "Report a vulnerability").

Helpful details to include:

- The affected component (iOS app, web app, or AWS backend) and commit
- Steps to reproduce, or a proof of concept
- The impact you expect (for example, credential exposure or unauthorized API use)

## What to expect

This is a personal project maintained on a best-effort basis.

- You should get an acknowledgement within 7 days.
- Once the issue is confirmed, a fix is made as soon as practical, and a
  GitHub security advisory is published when appropriate.
- Credit is given in the advisory unless you prefer to stay anonymous.
