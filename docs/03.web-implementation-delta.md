## 1. フロントエンド技術スタック

| 項目 | 要件 (`02.design-doc.md`) | 実際の実装 | 状態 |
|------|--------------------------|------------|------|
| フレームワーク | React 19 + TypeScript + Vite | 同左 | ✅ |
| CSS | Tailwind CSS v4 | 同左 | ✅ |
| 状態管理 | **Zustand**（再生キュー・設定） | **React useState + localStorage**（Zustand未導入） | 🔄 |
| IndexedDB ラッパー | **`idb` ライブラリ**使用 | **生 IDB API**（Promise を自前でラップ） | 🔄 |
| DnD | `@dnd-kit/sortable`（例文並び替え） | 未導入 | ⏳ |
| UIコンポーネント | 指定なし | **shadcn/ui** を導入 | ➕ |

### 変更理由・背景
- **Zustand**: PoC フェーズでは再生キュー管理が不要なため、シンプルな `useState` で十分と判断。Phase 1 の連続再生実装時に導入予定。
- **`idb`**: 外部依存を減らすため生 IDB API で実装。動作に問題なければこのまま継続。
- **shadcn/ui**: iOS ネイティブに近い UI を素早く実現するために採用。設計書に明示はなかったが、デザインの一貫性向上に貢献。

## 3. データ永続化

| 項目 | 要件 (`03.db-design.md`) | 実際の実装 | 状態 |
|------|--------------------------|------------|------|
| DB名 | `EnglishLearnDB` | 同左 | ✅ |
| DB バージョン | `1` | `1`（`audio_cache` 追加済みだがバージョン据え置き） | 🔄 |
| `words` ストア | ✅ スキーマ定義あり | openDB 内に定義あり（PoC では未使用、静的データ） | ⏳ |
| `sentences` ストア | ✅ スキーマ定義あり | openDB 内に定義あり（PoC では未使用） | ⏳ |
| `audio_cache` ストア | ✅ スキーマ定義あり | 実装・動作確認済み | ✅ |
| キャッシュ上限 | **100 MB** 推奨 | **50 MB** に変更 | 🔄 |
| LRU 退避 | `last_accessed_at` 基準 | 同左 | ✅ |
| localStorage 設定 | enVoice / jaVoice / voicevoxStyle / voicevoxApiKey / openAIKey / openAIModel / playPattern / intervalSec | 同左（全項目実装） | ✅ |

### 変更理由・背景
- **DBバージョン**: PoC 段階で既存 DB を持つユーザーが少ないため暫定的に `1` のまま。本番前に `2` へ上げる（Issue #138）。
- **キャッシュ上限 50 MB**: PoC での検証コスト削減と端末ストレージへの配慮。本番ではユーザー設定可能にする予定。
