# ずんだもんの立ち絵を表示する

Web 版では、ずんだもんの声で読み上げている間、画面右下に立ち絵が出ます。読み上げ中は小さく揺れ、口が声の大きさに合わせて開閉します。

## 動き方

- ずんだもんが話している間だけ表示します。連続再生では例文と例文の間にも間隔があるので、話し終えてから 1.5 秒は表示を残し、出たり消えたりを繰り返さないようにしています。
- VOICEVOX の音声(キャッシュ済みのものも含む)は、WAV の音量を 40 ミリ秒ごとに計算します。再生位置の音量が一番大きいところの 25% を超えると口を開けます。
- 接続先や API キーがなくブラウザの音声で読むときは、音量が取れないので、一定のリズムで口を動かします。
- OS で「視差効果を減らす」(`prefers-reduced-motion`)を有効にしていると、揺れは止まり、口パクだけになります。
- 立ち絵はタップを妨げません。下に重なったボタンもそのまま押せます。

## 立ち絵の画像を置く

このリポジトリは public なので、立ち絵の画像は含めていません。画像がないあいだは、仮のキャラクターを描いて表示します。

自分で用意した画像を使うときは、口を閉じた絵と開けた絵の透過 PNG を 2 枚、次の場所に置きます。`web/public/zundamon/` は `.gitignore` に入っているので、コミットされません。

```text
web/public/zundamon/mouth-closed.png
web/public/zundamon/mouth-open.png
```

- 2 枚は同じキャンバスサイズにしてください。重ねて切り替えるので、位置がずれると口以外も動いて見えます。
- 縦長の絵を想定しています。表示枠はスマホ幅で 128×160px、640px 以上で 160×208px で、絵は枠の下端に揃えて縦横比を保ったまま縮めます。
- どちらか 1 枚でも読み込めないときは、仮のキャラクターに戻ります。
- 置いたあとは、ページを再読み込みすれば反映されます。

## 画像の利用条件

画像は、東北ずん子・ずんだもんプロジェクトの[キャラクター利用の手引き](https://zunko.jp/guideline.html)に沿って用意してください。2026-11-22 に読んだ時点の要点は次のとおりです。

- 非商用であれば申請は要りません。公式の[素材ページ](https://zunko.jp/con_illust.html)の素材が使えます。
- 改変は「ずんだもんとわかる範囲で、イメージを極端に悪くしない」ことが条件です。口パク用の差分作りやアニメーションは名指しされていませんが、この条件の範囲と読めます。
- 東北 6 県以外の個人が有料アプリなどの商用で使うときは、別途ライセンスが必要になることがあります。
- 他の人が作った立ち絵(BOOTH で配布されているものなど)は、作者の規約にも従います。

`npm run build` すると `public/` の中身は `dist/` に入ります。ビルドしたものを公開すると画像も配布することになるので、そのときは配布してよい画像か確かめてください。
