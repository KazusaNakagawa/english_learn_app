# Installing the web app (PWA)

The web app is an installable PWA (#290). It is served from `localhost` by the launcher (`npx english-learn-app`), which browsers treat as a secure context, so installing works without HTTPS.

## Install

- Chrome / Edge: use the install icon in the address bar, or the menu > "Install English Learn App".
- Safari (iOS): Share > "Add to Home Screen".

## Offline behaviour

- The app shell and your word list (stored in IndexedDB) work offline.
- `/api/*` (the launcher's sentence generation), VOICEVOX and OpenAI are never cached. Offline, they fail and the app shows its usual error.

## Updates

A new build is detected when the app is opened. A banner "新しいバージョンがあります" appears; "更新する" reloads onto the new version, "あとで" keeps the current one until the next launch.

## Notes for development

- `npm run dev` does not register a service worker. Use `npm run build && npm run preview` to test installation and offline mode.
- Manifest and the network-only list live in `web/pwa-manifest.ts`; the service worker is generated by `vite-plugin-pwa` (Workbox `generateSW`).
- Icons in `web/public/` are resized from the iOS app icon. The maskable entry reuses the same image, so a platform's mask may crop its edges.
- Speech recognition in the installed app is not verified yet; file an issue for anything that differs from the browser tab.
