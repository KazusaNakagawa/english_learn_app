# アプリの使い方

## 画面構成

```
単語リスト → 例文一覧 → 発音練習
```

## 1. 単語リスト画面

アプリ起動時に表示される画面です。

### 表示内容
- 単語名
- 発音記号
- 日本語訳
- 例文数バッジ（例：「30例文」）

### 操作
- **スピーカーアイコン** をタップ → 単語の発音を再生
- **単語の行** をタップ → 例文一覧画面へ移動

## 2. 例文一覧画面

選択した単語の例文がカテゴリ別に表示されます。

### 表示内容
- 単語情報（単語、発音記号、意味）
- 「発音を聞く」ボタン
- カテゴリごとにグループ化された例文リスト

### 操作
- **「発音を聞く」** をタップ → 単語の発音を再生
- **例文の行** をタップ → 発音練習画面へ移動

## 3. 発音練習画面

例文の発音を練習する画面です。

### 表示内容
- 英語の例文
- 日本語訳
- カテゴリタグ
- 「お手本を聞く」ボタン
- 「発音する」ボタン
- 認識結果
- 判定結果

### 操作手順

1. **「お手本を聞く」** をタップ
   - ネイティブの発音が再生されます
   - 何度でも聞けます

2. **「発音する」** をタップ
   - 録音が開始されます（ボタンが赤くなる）
   - 例文を発音してください

3. **もう一度「発音する」** をタップ
   - 録音が停止し、判定が行われます

4. **結果を確認**
   - 「完璧です！」→ 正解
   - 「惜しい！」→ 近い発音
   - 「もう一度練習しましょう」→ 不正解

## 判定の仕組み

音声認識で認識されたテキストと、正解の例文を比較します。

| 結果 | 条件 |
|------|------|
| 完璧です！ | 完全一致 |
| 惜しい！ | 部分一致（一部が正しい） |
| もう一度練習しましょう | 不一致 |
| 音声が認識されませんでした | 音声が検出されなかった |

## Tips

### より正確に認識させるコツ
- 静かな環境で練習する
- マイクに近づいて発音する
- ゆっくり、はっきり発音する
- お手本を何度も聞いてから練習する

### 効果的な練習方法
1. まずお手本を2〜3回聞く
2. お手本に合わせてシャドーイング
3. 自分だけで発音して録音
4. 判定結果を確認
5. 間違えた部分を意識して再挑戦

## トラブルシューティング

### 音声が再生されない
- iPhoneの音量を確認
- サイレントモードを解除

### 発音が認識されない
- マイクの権限を確認（設定 → EnglishLearnApp → マイク）
- 音声認識の権限を確認（設定 → EnglishLearnApp → 音声認識）
- インターネット接続を確認（音声認識にはネット接続が必要）

### 権限を後から許可する方法
1. iPhoneの **設定** アプリを開く
2. 下にスクロールして **EnglishLearnApp** をタップ
3. **マイク** と **音声認識** をオンにする
