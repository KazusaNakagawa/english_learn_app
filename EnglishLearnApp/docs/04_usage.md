# アプリの使い方

## 画面構成

```
単語リスト → 例文一覧 → 発音練習
```

画面下部のタブで「学習」と「設定」を切り替えます。設定画面は [06_settings.md](./06_settings.md)、検索・編集・ゴミ箱の詳細は [07_word_management.md](./07_word_management.md) を参照してください。

## 1. 単語リスト画面

アプリ起動時に表示される画面です。

### 表示内容
- 単語名
- 発音記号
- 日本語訳
- 例文数バッジ（例：「30例文」）

### 操作
- **スピーカーアイコン** をタップ → 単語の発音を再生
- **単語の行** をタップ → 例文一覧画面へ移動
- 検索バーで単語・日本語訳・発音記号を横断検索
- 頭文字バーまたはカテゴリチップでフィルタ
- ▶ ボタンで連続再生開始
- 右スワイプ → 編集、左スワイプ → アーカイブ / ゴミ箱

## 2. 単語追加画面

1. 英単語を入力
2. 「例文を生成」をタップ → OpenAI が例文・日本語訳・発音記号を自動入力
3. 内容を確認して「保存」

例文の生成には OpenAI の API キーが必要です（[06_settings.md](./06_settings.md#3-openai-api設定)）。生成の条件は [例文生成の条件](./06_settings.md#5-例文生成の条件) で変えられます。

## 3. 例文一覧画面

選択した単語の例文がカテゴリ別に表示されます。

### 表示内容
- 単語情報（単語、発音記号、意味）
- 「発音を聞く」ボタン
- カテゴリごとにグループ化された例文リスト

### 操作
- **「発音を聞く」** をタップ → 単語の発音を再生
- **例文の ▶** をタップ → その例文からキューに追加して連続再生開始
- **例文の行** をタップ → 発音練習画面へ移動
- 連続再生中は再生中の例文まで自動スクロール

## 4. 発音練習画面

例文の発音を練習する画面です。

### 表示内容
- 英語の例文
- 日本語訳
- カテゴリタグ
- 「英語を聞く」「日本語を聞く」ボタン
- 「発音する」ボタン
- 認識結果
- 判定結果

### 操作手順

1. **「英語を聞く」** をタップ
   - お手本の発音が再生されます
   - 何度でも聞けます

2. **「発音する」** をタップ
   - 録音が開始されます（「録音中...タップで停止」と表示）
   - 例文を発音してください

3. **もう一度ボタン** をタップ
   - 録音が停止し、判定が行われます

4. **結果を確認**（下の表）

## 判定の仕組み

音声認識で認識されたテキストと、正解の例文を比較します。

| 結果 | 条件 |
|------|------|
| 完璧です！ | 完全一致 |
| 惜しい！もう一度試してみましょう | 部分一致（一部が正しい） |
| もう一度聞いて練習しましょう | 不一致 |
| 音声が認識されませんでした | 音声が検出されなかった |

## 5. 連続再生（フルプレイヤー）

- 連続再生モードは、バイリンガル（英→日→英）か英語のみ（英→英）を設定画面で選べます
- 画面下部のミニプレイヤーをタップして全画面表示
- 再生中の行まで自動スクロール
- ドラッグで順番を入れ替え、スワイプで個別削除、タップでその位置から再生
- ロック画面からも操作可能（前後スキップ、一時停止）

## 権限

初回起動時に以下の許可が必要です：

| 権限 | 用途 |
|------|------|
| マイク | 発音の録音 |
| 音声認識 | 発音の正誤判定 |

許可しない場合、発音チェック機能は使用できません（それ以外の機能は正常に動作します）。

## Tips

### より正確に認識させるコツ
- 静かな環境で練習する
- マイクに近づいて発音する
- ゆっくり、はっきり発音する
- お手本を何度も聞いてから練習する

### 効果的な練習方法
1. まずお手本を2〜3回聞く
2. お手本に合わせてシャドーイング
3. 自分だけで発音して録音
4. 判定結果を確認
5. 間違えた部分を意識して再挑戦

## トラブルシューティング

### 音声が再生されない
- iPhoneの音量を確認
- サイレントモードを解除
- ずんだもんの場合は [06_settings.md](./06_settings.md#ずんだもんの音声が再生されない) を参照

### 発音が認識されない
- マイクの権限を確認（設定 → EnglishLearnApp → マイク）
- 音声認識の権限を確認（設定 → EnglishLearnApp → 音声認識）
- インターネット接続を確認（音声認識はサーバー処理のため、実機ではネット接続が必要）
- シミュレーターではマイク機能に制限があります（実機での使用を推奨）

### 権限を後から許可する方法
1. iPhoneの **設定** アプリを開く
2. 下にスクロールして **EnglishLearnApp** をタップ
3. **マイク** と **音声認識** をオンにする
