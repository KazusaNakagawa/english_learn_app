# 設定画面ガイド

アプリ下部タブの **「設定」** から開く画面です。音声・API・AIモデル・例文生成条件をカスタマイズできます。

---

## 設定項目一覧

| セクション | 設定内容 |
|-----------|---------|
| 音声設定 | 読み上げ音声の種類（デフォルト / 女性 / 男性 / ずんだもん） |
| VOICEVOX設定 | ずんだもん使用時のサーバーURL・スタイル（ずんだもん選択時のみ表示） |
| OpenAI API設定 | 例文自動生成に使うAPIキー |
| AIモデル設定 | 例文生成に使うGPTモデルの切り替え |
| 例文生成の条件 | 例文生成プロンプトの条件部分をカスタマイズ |

---

## 1. 音声設定

例文・単語の読み上げ音声を選択します。

### 操作手順

1. **設定タブ** を開く
2. **「音声設定」** セクションの性別セグメントをタップ
3. 以下から選択する

| 選択肢 | 説明 |
|-------|------|
| デフォルト | iOSシステムのデフォルト英語音声 |
| 女性 | 女性の英語音声 |
| 男性 | 男性の英語音声 |
| ずんだもん | VOICEVOX経由のずんだもん音声（要サーバー設定） |

4. **「サンプルを再生」** をタップして音声を確認する
5. 設定は自動保存される

> **Note:** ずんだもんを選択すると、直下に **VOICEVOX設定** セクションが表示されます。

---

## 2. VOICEVOX設定（ずんだもん）

ずんだもん音声はVOICEVOX ENGINEサーバーと通信して音声を生成します。音声設定で「ずんだもん」を選んだ場合のみ表示されます。

### ライセンス・クレジット表記

ずんだもんの音声ライブラリを使用する場合、**商用・非商用を問わず** 以下のクレジット表記が必要です。

```
VOICEVOX:ずんだもん
```

アプリ内では VOICEVOX設定セクションにクレジットを表示しています。アプリを公開・配布する際は、ストア説明文やアプリ内のクレジット画面にも同様の表記を追加してください。

### 前提条件

DockerでVOICEVOX ENGINEが稼働していること。

```bash
# Docker でVOICEVOX ENGINEを起動する例
docker run --rm -p 50021:50021 voicevox/voicevox_engine:cpu-ubuntu20.04-latest
```

起動成功時のログ：
```
INFO:     Uvicorn running on http://0.0.0.0:50021 (Press CTRL+C to quit)
```

### ⚠️ 英語テキストの読み上げについて

VOICEVOX は日本語TTS エンジンのため、英語テキストを送ると **日本語の音韻ルールで読み上げます**（カタカナ英語的な発音）。英語のネイティブ発音には対応していません（2026年2月時点）。

英語の正確な発音練習には「デフォルト / 女性 / 男性」の音声設定を使用してください。

### Mac（Docker）+ iPhone のセットアップ手順

iPhone と Mac が **同じ Wi-Fi** に接続されている必要があります。

**ステップ1：Mac のローカル IP を確認する**

```bash
ipconfig getifaddr en0
```

例：`192.168.1.5` と表示された場合、これがサーバーURLに使うIPアドレスです。

**ステップ2：疎通確認**

iPhone のブラウザで以下にアクセスする：

```
http://192.168.1.5:50021/version
```

`"latest"` のような文字列が返れば接続成功です。

**ステップ3：Info.plist に ATS 設定を追加する（初回のみ）**

iOS はデフォルトで `http://` 通信をブロックします。Xcode で `Info.plist` に以下を追加してリビルドしてください：

```xml
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowsArbitraryLoads</key>
    <true/>
</dict>
```

**ステップ4：アプリにURLを入力する**

1. 音声設定で **「ずんだもん」** を選択する
2. **「VOICEVOX設定」** セクションが出現する
3. サーバーURLに入力する：

   ```
   http://192.168.1.5:50021
   ```

   （末尾の `/` は不要）

### 操作手順（VPS の場合）

1. 音声設定で **「ずんだもん」** を選択する
2. **「VOICEVOX設定」** セクションが出現する
3. **サーバーURL** を入力する

   ```
   http://{VPSのパブリックIP}:50021
   ```

   VPS のパブリック IP は VPS 上で `curl ifconfig.me` で確認できます。

4. **スタイル** を選択する

   | スタイル | 特徴 |
   |---------|------|
   | ノーマル | 標準のずんだもん音声 |
   | あまあま | 甘い話し方 |
   | ツンツン | ツンツンした話し方 |
   | セクシー | セクシーな話し方 |
   | ささやき | ささやき声 |
   | ヒソヒソ | ヒソヒソ声 |

5. 発音練習・例文画面で **「お手本を聞く」** をタップするとずんだもん音声で再生される

### 通信の仕組み

```
iOS アプリ
  │
  ├─ POST /audio_query?text={テキスト}&speaker={スタイルID}
  │    └─ 音声クエリ（JSON）を取得
  │
  └─ POST /synthesis?speaker={スタイルID}  ＋ 音声クエリ
       └─ WAV音声データを取得 → 再生
```

## 3. OpenAI API設定

単語追加時の例文自動生成に使うAPIキーを設定します。

### 操作手順

1. **「OpenAI API設定」** セクションを開く
2. **「APIキー」** フィールドをタップ
3. OpenAIのAPIキー（`sk-...`）を入力する
4. 入力後に緑のチェックマーク **「APIキーが設定されています」** が表示されれば完了

### APIキーの取得方法

1. [platform.openai.com](https://platform.openai.com) にアクセス
2. ログイン → 右上メニュー → **API keys**
3. **「+ Create new secret key」** をクリック
4. 生成されたキー（`sk-...`）をコピーしてアプリに貼り付ける

> **Note:** APIキーはUserDefaultsに保存されます。他者と共有しないよう注意してください。

---

## 4. AIモデル設定

例文生成に使うOpenAIモデルをプルダウンで切り替えます。

### 操作手順

1. **「AIモデル設定」** セクションの **「使用モデル」** をタップ
2. 一覧からモデルを選択する

| モデル | 特徴 |
|-------|------|
| GPT-4o mini（高速・低コスト） | デフォルト。速くてコストが低い |
| GPT-4o（高性能） | より自然で高品質な例文を生成 |
| GPT-4 Turbo | GPT-4の高速版 |
| GPT-3.5 Turbo（最安価） | 最もコストが低い |

3. 選択は自動保存される。次回の例文生成から新しいモデルが使われる

---

## 5. 例文生成の条件

単語追加時にOpenAIへ送るプロンプトの「条件」部分を編集できます。

### デフォルト内容

```
条件：
- 日常会話、ビジネス、学習など多様なシーンの例文を含めてください
- カテゴリは「日常会話」「ビジネス」「学習・教育」「趣味・娯楽」「旅行」などから適切なものを選んでください
- 自然で実用的な例文にしてください
- 日本語訳は自然な日本語にしてください
```

### 操作手順

1. **「例文生成の条件」** セクションのテキストエリアをタップ
2. 条件を自由に編集する

   **カスタマイズ例：**
   ```
   条件：
   - TOEIC頻出フレーズを優先してください
   - ビジネスメールで使える例文を多く含めてください
   - 難易度は中級（CEFR B1〜B2）を目安にしてください
   ```

3. 編集内容は自動保存される。次回の例文生成から反映される

### デフォルトに戻す

1. **「デフォルトに戻す」** ボタン（赤文字）をタップ
2. 確認アラートで **「リセット」** をタップ

## 操作フローまとめ

### 音声をずんだもんに切り替えて練習する

```
設定タブ
  └─ 音声設定 → ずんだもん を選択
       └─ VOICEVOX設定 セクションが表示される
            ├─ サーバーURL を入力
            └─ スタイルを選択
                 └─ 学習タブ → 単語 → 例文 → 発音練習
                      └─「お手本を聞く」→ ずんだもんが読み上げる
```

### 例文生成をカスタマイズして単語を追加する

```
設定タブ
  ├─ AIモデル設定 → 使用モデルを選択
  └─ 例文生成の条件 → 条件を編集
       └─ 学習タブ → ＋ボタン → 単語・意味を入力 →「例文を生成」
            └─ カスタマイズした条件で例文が生成される
```

## トラブルシューティング

### ずんだもんの音声が再生されない

- サーバーURLが正しいか確認する（末尾の `/` は不要）
- Dockerコンテナが起動しているか確認する（`Uvicorn running on http://0.0.0.0:50021` のログが出ているか）
- **Mac+Docker の場合：** iPhone と Mac が同じ Wi-Fi に接続されているか確認する
- **Mac+Docker の場合：** `ipconfig getifaddr en0` で取得した IP を使っているか確認する
- **Mac+Docker の場合：** `Info.plist` に `NSAllowsArbitraryLoads: true` を追加してリビルドしたか確認する
- 外部VPSの場合、ポート50021がファイアウォールで開放されているか確認する
- iPhone のブラウザで `http://{IP}:50021/version` にアクセスして疎通確認する

### ずんだもんが英語をうまく発音しない

VOICEVOX は日本語TTS エンジンのため、英語テキストは日本語音韻ルールで読み上げます（カタカナ英語的な発音）。英語のネイティブ発音を聞くには「デフォルト / 女性 / 男性」の音声に切り替えてください。VOICEVOX の英語対応は開発中です（[Issue #1524](https://github.com/VOICEVOX/voicevox_engine/issues/1524)）。

### 例文が生成されない

- APIキーが正しく設定されているか確認する（緑チェックが表示されているか）
- インターネット接続を確認する
- 選択したモデルがAPIキーのプランで利用可能か確認する（GPT-4系は有料プランが必要）

### 音声設定が反映されない

- アプリを再起動する
- 設定タブで「サンプルを再生」して動作確認する
