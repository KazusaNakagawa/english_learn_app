# 設定画面ガイド

アプリ下部タブの **「設定」** から開く画面です。音声・API・AIモデル・例文生成条件をカスタマイズできます。

---

## 設定項目一覧

| セクション | 設定内容 |
|-----------|---------|
| 英語の音声設定 | デフォルト / 女性 / 男性 / ずんだもん |
| 日本語の音声設定 | ずんだもん / デフォルト |
| 連続再生設定 | モード（バイリンガル / 英語のみ）、例文間の間隔（0.5〜3.0 秒） |
| OpenAI API設定 | 例文自動生成に使うAPIキー |
| VOICEVOX設定 | ずんだもんのスタイル（接続先は `AppConfig.swift`）（ノーマル / あまあま / ツンツン / セクシー / ささやき / ヒソヒソ）。ずんだもん選択時のみ表示 |
| AIモデル設定 | 例文生成に使うGPTモデルの切り替え |
| 例文生成の条件 | プロンプトプリセットの選択・管理 |
| データ管理 | JSON エクスポート / インポート、音声キャッシュのクリア |
| 法的情報 | プライバシーポリシー、利用規約 |

---

## 1. 音声設定

例文・単語の読み上げ音声を、英語と日本語で別々に選択します。

### 操作手順

1. **設定タブ** を開く
2. **「英語の音声設定」** / **「日本語の音声設定」** セクションのセグメントをタップ
3. 以下から選択する

| 選択肢 | 説明 |
|-------|------|
| デフォルト | iOSシステムのデフォルト音声 |
| 女性 | 女性の英語音声（英語のみ） |
| 男性 | 男性の英語音声（英語のみ） |
| ずんだもん | VOICEVOX経由のずんだもん音声（要 `AppConfig.swift` の設定） |

4. **「英語サンプルを再生」** / **「日本語サンプルを再生」** をタップして音声を確認する
5. 設定は自動保存される

> **Note:** ずんだもんを選択すると、直下に **VOICEVOX設定** セクションが表示されます。

## 2. VOICEVOX設定（ずんだもん）

ずんだもん音声は、VOICEVOX ENGINE と通信して音声を作ります。英語か日本語の音声で「ずんだもん」を選んだときだけ、このセクションが表示されます。

アプリの画面で選べるのは **スタイル** だけです。**接続先と API キーはアプリの画面では入力できず**、ビルド前に `AppConfig.swift` に書きます（[01_setup.md](./01_setup.md#3-設定ファイルの作成)）。

### ライセンス・クレジット表記

ずんだもんを使うときは「VOICEVOX:ずんだもん」の表記が必要です。アプリ内では VOICEVOX設定セクションに表示しています。規約と表記場所は [docs/voices.md](../../docs/voices.md#クレジットとライセンス) にまとめています。アプリを公開・配布する際は、ストア説明文にも同じ表記を追加してください。

### 接続先を設定する（AppConfig.swift）

```swift
enum AppConfig {
    static let voicevoxBaseURL = "https://xxxxxxxxxx.execute-api.ap-northeast-1.amazonaws.com"  // 末尾の / は不要
    static let voicevoxApiKey = "..."
}
```

- `voicevoxBaseURL` が空のときは、ずんだもんの音声を取得しません。
- `voicevoxApiKey` が空のときも取得しません。API キーを確認しないエンジン（ローカルの Docker など）を使う場合も、空でない値（`local` など）を入れてください。値は `x-api-key` ヘッダーで送られ、エンジン側では無視されます。
- 値を変えたら、アプリをビルドし直します。
- 取得に失敗したときは、iOS の音声に切り替えずに、その文を読まずに次へ進みます。

| 接続先 | `voicevoxBaseURL` | `voicevoxApiKey` |
|------|------|------|
| AWS（このリポジトリの CDK スタック） | デプロイ時に出力される API Gateway の URL | Secrets Manager の値（[docs/02.voicevox_api_authentication.md](../../docs/02.voicevox_api_authentication.md)） |
| Mac の Docker（同じ Wi-Fi の iPhone から） | `http://{Mac の IP}:50021` | 空でない任意の値 |

> ⚠️ API キーはアプリのバイナリに埋め込まれます。`AppConfig.swift` はコミットしないでください。

### Mac の Docker で動かす（開発用）

iPhone と Mac が **同じ Wi-Fi** に接続されている必要があります。

**ステップ1：エンジンを起動する**

iPhone から接続できるように、`127.0.0.1` ではなく全インターフェースに公開します。同じ LAN の他の端末からも使えるので、信頼できるネットワークでだけ使ってください。

```bash
docker run --rm -p 50021:50021 voicevox/voicevox_engine:cpu-0.25.1
```

起動成功時のログ：
```
INFO:     Uvicorn running on http://0.0.0.0:50021 (Press CTRL+C to quit)
```

バージョンは AWS 側のスタックと Web 版の手順（[docs/web/local-voicevox.md](../../docs/web/local-voicevox.md)）に揃えています。

**ステップ2：Mac のローカル IP を確認する**

```bash
ipconfig getifaddr en0
```

例：`192.168.1.5` と表示された場合、`voicevoxBaseURL` は `http://192.168.1.5:50021` です。

**ステップ3：疎通確認**

iPhone のブラウザで `http://192.168.1.5:50021/version` を開きます。バージョン番号が返れば接続できています。

**ステップ4：Info.plist に ATS 設定を追加する（初回のみ）**

iOS はデフォルトで `http://` 通信をブロックします。Xcode で `Info.plist` の `NSAppTransportSecurity` を以下のように **特定IPのみ許可するスコープ設定** にしてリビルドしてください：

```xml
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSExceptionDomains</key>
    <dict>
        <!-- VOICEVOXサーバーのIPまたはホスト名に置き換える -->
        <key>192.168.1.5</key>
        <dict>
            <key>NSExceptionAllowsInsecureHTTPLoads</key>
            <true/>
        </dict>
    </dict>
</dict>
```

> **⚠️ セキュリティ注意：** `NSAllowsArbitraryLoads: true` はすべての HTTP 通信を許可してしまうため使用しないでください。上記のように `NSExceptionDomains` で VOICEVOXサーバーのIPのみに限定してください。

**ステップ5：`AppConfig.swift` を書き換えてビルドする**

`voicevoxBaseURL` に `http://192.168.1.5:50021`、`voicevoxApiKey` に空でない任意の値を入れ、`Cmd + R` で実行します。

### スタイルを選ぶ

1. 英語か日本語の音声で **「ずんだもん」** を選択する
2. **「VOICEVOX設定」** セクションの **スタイル** を選択する

   | スタイル | 特徴 |
   |---------|------|
   | ノーマル | 標準のずんだもん音声 |
   | あまあま | 甘い話し方 |
   | ツンツン | ツンツンした話し方 |
   | セクシー | セクシーな話し方 |
   | ささやき | ささやき声 |
   | ヒソヒソ | ヒソヒソ声 |

3. サンプルボタンか、発音練習画面の **「英語を聞く」「日本語を聞く」** で確認する

### ⚠️ 英語テキストの読み上げについて

VOICEVOX は日本語TTS エンジンのため、英語テキストを送ると **日本語の音韻ルールで読み上げます**（カタカナ英語的な発音）。英語の正確な発音練習には「デフォルト / 女性 / 男性」を使用してください。

### 通信の仕組み

```
iOS アプリ（x-api-key ヘッダー付き）
  │
  ├─ POST /audio_query?text={テキスト}&speaker={スタイルID}
  │    └─ 音声クエリ（JSON）を取得
  │
  └─ POST /synthesis?speaker={スタイルID}  ＋ 音声クエリ
       └─ WAV音声データを取得 → キャッシュして再生
```

## 3. OpenAI API設定

単語追加時の例文自動生成に使うAPIキーを設定します。

### 操作手順

1. **「OpenAI API設定」** セクションを開く
2. **「APIキー」** フィールドをタップ
3. OpenAIのAPIキー（`sk-...`）を入力する
4. 入力後に緑のチェックマーク **「APIキーが設定されています」** が表示されれば完了

### APIキーの取得方法

1. [platform.openai.com](https://platform.openai.com) にアクセス
2. ログイン → 右上メニュー → **API keys**
3. **「+ Create new secret key」** をクリック
4. 生成されたキー（`sk-...`）をコピーしてアプリに貼り付ける

> **Note:** APIキーは iOS Keychain に保存されます。他者と共有しないよう注意してください。

## 4. AIモデル設定

例文生成に使うOpenAIモデルをプルダウンで切り替えます。

### 操作手順

1. **「AIモデル設定」** セクションの **「使用モデル」** をタップ
2. 一覧からモデルを選択する

| モデル | 特徴 |
|-------|------|
| GPT-4o mini（高速・低コスト） | デフォルト。速くてコストが低い |
| GPT-4o（高性能） | より自然で高品質な例文を生成 |
| GPT-4 Turbo | GPT-4の高速版 |
| GPT-3.5 Turbo（最安価） | 最もコストが低い |

3. 選択は自動保存される。次回の例文生成から新しいモデルが使われる

## 5. 例文生成の条件

単語追加時にOpenAIへ送るプロンプトの「条件」部分を編集できます。

### デフォルト内容

```
条件：
- 日常会話、ビジネス、学習など多様なシーンの例文を含めてください
- カテゴリは「日常会話」「ビジネス」「学習・教育」「趣味・娯楽」「旅行」などから適切なものを選んでください
- 自然で実用的な例文にしてください
- 日本語訳は自然な日本語にしてください
```

### 操作手順

1. **「例文生成の条件」** セクションのテキストエリアをタップ
2. 条件を自由に編集する

   **カスタマイズ例：**
   ```
   条件：
   - TOEIC頻出フレーズを優先してください
   - ビジネスメールで使える例文を多く含めてください
   - 難易度は中級（CEFR B1〜B2）を目安にしてください
   ```

3. 編集内容は自動保存される。次回の例文生成から反映される

### デフォルトに戻す

1. **「デフォルトに戻す」** ボタン（赤文字）をタップ
2. 確認アラートで **「リセット」** をタップ

## 操作フローまとめ

### 音声をずんだもんに切り替えて練習する

```
（ビルド前）AppConfig.swift に接続先と API キーを書く
  └─ 設定タブ → 英語 / 日本語の音声設定 → ずんだもん を選択
       └─ VOICEVOX設定 セクションでスタイルを選択
            └─ 学習タブ → 単語 → 例文 → 発音練習
                 └─「英語を聞く」/「日本語を聞く」→ ずんだもんが読み上げる
```

### 例文生成をカスタマイズして単語を追加する

```
設定タブ
  ├─ AIモデル設定 → 使用モデルを選択
  └─ 例文生成の条件 → 条件を編集
       └─ 学習タブ → ＋ボタン → 単語・意味を入力 →「例文を生成」
            └─ カスタマイズした条件で例文が生成される
```

## トラブルシューティング

### ずんだもんの音声が再生されない

- `AppConfig.swift` の `voicevoxBaseURL` と `voicevoxApiKey` がどちらも空でないか確認し、書き換えたらビルドし直す（Docker でもキーは空にできない）
- `voicevoxBaseURL` の末尾に `/` を付けていないか確認する
- 英語の音声 / 日本語の音声で「ずんだもん」が選択されているか確認する
- AWS の場合：API キーが Secrets Manager の値と一致しているか確認する（[docs/02.voicevox_api_authentication.md](../../docs/02.voicevox_api_authentication.md)）
- **Mac+Docker の場合：** コンテナが起動しているか（`Uvicorn running on http://0.0.0.0:50021` のログ）、`-p 50021:50021` で公開しているか確認する
- **Mac+Docker の場合：** iPhone と Mac が同じ Wi-Fi で、`ipconfig getifaddr en0` の IP を使っているか確認する
- **Mac+Docker の場合：** `Info.plist` の `NSExceptionDomains` にその IP を追加してリビルドしたか確認する
- iPhone のブラウザで `http://{IP}:50021/version` にアクセスして疎通確認する

### ずんだもんが英語をうまく発音しない

VOICEVOX は日本語TTS エンジンのため、英語テキストは日本語音韻ルールで読み上げます（カタカナ英語的な発音）。英語のネイティブ発音を聞くには「デフォルト / 女性 / 男性」の音声に切り替えてください。VOICEVOX の英語対応は開発中です（[Issue #1524](https://github.com/VOICEVOX/voicevox_engine/issues/1524)）。

### 例文が生成されない

- APIキーが正しく設定されているか確認する（緑チェックが表示されているか）
- インターネット接続を確認する
- 選択したモデルがAPIキーのプランで利用可能か確認する（GPT-4系は有料プランが必要）
- API キーの使用制限・クレジット残高を OpenAI ダッシュボードで確認する

### 音声設定が反映されない

- アプリを再起動する
- 設定タブで「サンプルを再生」して動作確認する
