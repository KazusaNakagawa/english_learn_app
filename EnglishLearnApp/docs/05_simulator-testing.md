# iOS シミュレーターでの動作検証

## 概要

iOSシミュレーターはMac上で動作する仮想iPhoneです。実際のiPhone端末やUSBケーブルは不要です。

Xcodeのプレビュー（Canvas）はUIの見た目確認用で、UserDefaultsやファイル保存が正常に動作しません。機能のテストにはシミュレーターを使用してください。

## シミュレーターの起動手順

### 1. デバイスを選択

Xcode画面上部のデバイス選択をクリックし、**iOS Simulators** セクションからシミュレーターを選択します。

```
┌─────────────────────────────┐
│ iOS Simulators              │
│   iPhone 17          ← 選択 │
│   iPhone 17 Pro             │
│   iPhone 17 Pro Max         │
│   iPad Air 11-inch          │
├─────────────────────────────┤
│ Build Only Device    ← NG   │
└─────────────────────────────┘
```

> **注意**: 「Build Only Device」が選択されていると実行できません。必ずシミュレーターを選択してください。

### 2. アプリを実行

以下のいずれかの方法で実行します：

- **▶ ボタン**（再生ボタン）をクリック
- **Cmd + R** を押す

シミュレーターが別ウィンドウで起動し、アプリが実行されます。

## 動作検証項目

### 単語追加機能のテスト

1. **設定タブ** を開く
2. **OpenAI APIキー** を入力
3. **学習タブ** に戻る
4. 右上の **「+」ボタン** をタップ
5. 単語情報を入力：
   - 英単語: `ambitious`
   - 意味: `野心的な`
   - 発音記号: `æmˈbɪʃ.əs`
6. **「例文を自動生成」** をタップ
7. 例文が生成されたら **「保存」** をタップ
8. 単語リストに追加されていることを確認

### 永続化のテスト

1. 単語を追加した後、シミュレーターでアプリを閉じる
2. 再度アプリを起動
3. 追加した単語が残っていることを確認

## トラブルシューティング

### 「A build only device cannot be used to run this target」エラー

デバイス選択が「Build Only Device」になっています。iOS Simulatorsセクションからシミュレーターを選択してください。

### シミュレーターが見つからない

Xcode > Settings > Platforms から追加のシミュレーターをダウンロードできます。

### APIキーが保存されない

プレビュー（Canvas）ではなく、シミュレーターで実行しているか確認してください。

## プレビューとシミュレーターの違い

| 項目 | プレビュー (Canvas) | シミュレーター |
|------|---------------------|----------------|
| 用途 | UIの見た目確認 | 機能の動作検証 |
| UserDefaults | 動作しない | 正常に動作 |
| ファイル保存 | 動作しない | 正常に動作 |
| ネットワーク通信 | 制限あり | 正常に動作 |
| 起動方法 | コード内の `#Preview` | ▶ ボタン / Cmd + R |
