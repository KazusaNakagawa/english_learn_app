# 英語学習アプリ (EnglishLearnApp)

単語の発音練習ができるiOSアプリです。

## 機能

- **単語リスト表示** - 学習する英単語の一覧（日本語訳・発音記号付き）
- **例文練習** - 単語を使った例文で実践的な発音練習
- **音声読み上げ** - ネイティブ発音でお手本を再生
- **発音チェック** - 自分の発音を録音して正誤判定

## 動作環境

- macOS（Xcode 15以上）
- iOS 17.0以上（シミュレーターまたは実機）

## セットアップ手順

### 1. Xcodeをインストール

Xcodeがインストールされていない場合は、App Storeからインストールしてください。

1. App Storeを開く
2. 「Xcode」を検索
3. インストール（無料）

### 2. プロジェクトを開く

**方法A: Finderから開く**
1. Finderで `EnglishLearnApp` フォルダを開く
2. `EnglishLearnApp.xcodeproj` をダブルクリック

**方法B: ターミナルから開く**
```bash
open EnglishLearnApp/EnglishLearnApp.xcodeproj
```

### 3. アプリを実行

1. Xcodeの左上で実行先を選択
   - シミュレーター: 「iPhone 15」など任意のiPhoneを選択
   - 実機: USBで接続したiPhoneを選択
2. 再生ボタン（▶）をクリック、または `Cmd + R` を押す
3. 初回ビルド後、アプリが起動します

## 使い方

### 単語リスト画面
- 単語一覧が表示されます
- スピーカーアイコンをタップすると発音を聞けます
- 単語をタップすると例文一覧画面に移動します
- 例文がある単語には「30例文」のようなバッジが表示されます

### 例文一覧画面
- 単語の発音を確認できます
- 例文がカテゴリ別に表示されます
- 例文をタップすると発音練習画面に移動します

### 発音練習画面
1. **「お手本を聞く」** - ネイティブの発音を確認
2. **「発音する」** - タップして録音開始、もう一度タップで停止
3. 発音結果が表示されます
   - 完璧です！ - 正解
   - 惜しい！ - 近い発音
   - もう一度練習しましょう - 不正解

## 権限について

初回起動時に以下の許可を求められます：

- **マイク** - 発音の録音に使用
- **音声認識** - 発音の認識に使用

「許可」を選択してください。許可しないと発音チェック機能が使えません。

## 収録単語

### rarity（珍しさ・希少性）
30個の例文がカテゴリ別に収録されています：

| カテゴリ | 例文数 |
|----------|--------|
| 一般的な使い方 | 5 |
| ビジネス・マーケティング | 5 |
| コレクション・ゲーム | 5 |
| 科学・自然・環境 | 5 |
| 抽象的・比喩的 | 5 |
| 文学・詩的な表現 | 5 |

## 単語・例文の追加方法

`EnglishLearnApp/EnglishLearnApp/Resources/words.json` を編集して単語と例文を追加できます。

```json
{
  "id": "一意のUUID",
  "word": "英単語",
  "meaning": "日本語訳",
  "phonetic": "発音記号",
  "sentences": [
    {
      "id": "一意のUUID",
      "english": "英語の例文",
      "japanese": "日本語訳",
      "category": "カテゴリ名"
    }
  ]
}
```

新しい単語データは `EnglishLearnApp/data/` フォルダに `.md` ファイルとして追加し、JSON形式に変換してアプリに組み込むことができます。

## トラブルシューティング

### ビルドエラーが出る場合
- Xcodeを最新版にアップデートしてください
- Product > Clean Build Folder (`Cmd + Shift + K`) を実行してから再ビルド

### 音声認識が動かない場合
- 設定アプリ > EnglishLearnApp で権限が許可されているか確認
- 実機の場合、インターネット接続が必要です（音声認識はサーバー処理）

### シミュレーターでマイクが使えない場合
- シミュレーターではマイク機能に制限があります
- 発音チェック機能は実機での使用を推奨します
