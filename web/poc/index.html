3. VOICEVOX Lambda / CORS

⚠️ CORS Status — Action Required

The current CDK stack has no CORS configuration (// CORS removed: native iOS app does not require CORS). Browser fetch requests will be blocked by the browser's CORS preflight check. CORS must be added to the API Gateway before the Web app can call VOICEVOX Lambda.

Required CDK change (voicevox-stack.ts) 
// Before (iOS only — no CORS):
const httpApi = new apigatewayv2.HttpApi(this, 'VoicevoxHttpApi', {
  apiName: `voicevox-api-${stackEnv}`,
  description: `VOICEVOX TTS API (${stackEnv})`,
  // CORS removed: native iOS app does not require CORS
});

// After (Web + iOS):
const allowedOrigins = stackEnv === 'poc'
  ? ['*']                          // PoC: allow all origins
  : ['https://your-app-domain'];   // dev/pro: restrict to app domain

const httpApi = new apigatewayv2.HttpApi(this, 'VoicevoxHttpApi', {
  apiName: `voicevox-api-${stackEnv}`,
  description: `VOICEVOX TTS API (${stackEnv})`,
  corsPreflight: {
    allowOrigins: allowedOrigins,
    allowMethods: [apigatewayv2.CorsHttpMethod.POST, apigatewayv2.CorsHttpMethod.GET, apigatewayv2.CorsHttpMethod.OPTIONS],
    allowHeaders: ['Content-Type', 'x-api-key'],
    maxAge: cdk.Duration.days(1),
  },
});
